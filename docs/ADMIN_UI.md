# 관리자 화면 (실제 API 연결)

프론트 `NEXT_PUBLIC_DATA_MODE=mock|api` 환경변수로 목업과 실제 인증/API를 선택합니다. 최신 실행 방법, API 연결 범위와 외부 서비스 설정은 [API_INTEGRATION.md](API_INTEGRATION.md)를 확인하세요.

아래는 `NEXT_PUBLIC_DATA_MODE=mock`으로 실행했을 때의 기존 시연 가이드입니다.

# 관리자 화면

- 경로: `/admin` (수강생 포털 헤더의 **관리자 모드**로 진입, 관리자 헤더에서 수강생 모드로 복귀)
- 디자인: 기존 수강생 포털의 사이드바, Inspire LMS 브랜딩, shadcn 테마 토큰, 인디고 강조색, 라이트/다크 모드 공유
- 기본 데이터: Mock. 변경 사항은 `inspire-admin-demo-v1` localStorage에 저장하며 초기 비밀번호는 저장하지 않습니다.
- 모든 목록에서 검색, 상태/분류 필터, **빈 상태 보기**를 사용할 수 있습니다.
- **연결 설정 → Mock 데이터 초기화**로 초기 시연 데이터 복구

## 시연 흐름

1. 계정·기수: 계정 발급 → 권한/상태 수정 → 기수 등록 및 회원 배정
2. 출결·소명: 일자/회차 출결 등록·수정·논리 삭제 → 소명 승인/반려. **충돌 재현 → 승인**으로 버전 충돌 및 INVALIDATED/409 토스트 확인. 허용된 여섯 전환은 소명 승인으로만 변경합니다.
3. 게시판·Discord: 공지/FAQ/질문 등록·수정·삭제, 첨부 선택·제거, 질문의 답변 관리. PUBLIC과 슬러그를 설정한 공지를 전송하면 PENDING → SENT. 재전송은 차단합니다. 초기 실패 공지에서 재시도를 확인할 수 있습니다.
4. 영상·커리큘럼: 날짜·교시별 YouTube 등록 → 소단원 관리 → 시작 초/핵심 개념 설정. 과목 → 단원 → 개념 순서로 커리큘럼 관리
5. 과제·피드백: 담당 강사, 기한, 배점, 안내 및 첨부 관리 → 제출물 평가 → 파일 확인, 점수·피드백 등록/수정. 학생 수정 잠금 상태 표시
6. 역량평가·복습: 초안 → 문항/보기/정답/해설 작성 → 핵심 개념·복습 챕터 연결 → 게시 → 종료. 게시 이후 문항 편집 차단

## 백엔드 연결

**연결 설정**에서 API 모드, 기본 URL, 관리자 JWT 액세스 토큰을 설정합니다. 토큰은 메모리에만 보관합니다. 연결 실패 시 Mock 데이터를 대신 표시하지 않습니다. 실제 서버의 CORS 설정이 필요합니다.

`src/lib/admin-api.ts`는 기존 API의 JSON 응답, 페이지 순회, Bearer 인증, 204 응답, multipart 첨부, 한국 시각 오프셋, 409 충돌을 처리합니다. 계정·기수·출결·게시판·답변·과제·채점·평가의 기존 엔드포인트를 사용합니다.

현재 백엔드 브랜치에는 영상·커리큘럼·공개 링크·문항 복습 매핑·AI·Discord API가 추가되었습니다. 제출물 파일 조회·다운로드도 실제 연결되어 있습니다. Discord·AI는 서버 환경변수 설정이 필요합니다. MANAGER는 전역 계정 역할이 아닌 기수 등록 역할입니다.

Mock은 브라우저 데모이며 인증·권한 보안을 대신하지 않습니다. 실제 운영에서는 백엔드 JWT 및 역할 검증을 사용합니다.

## 검증

- `npx tsc --noEmit`
- `npm run lint`
- `npm run build`
- 기존 개발 서버가 `.next`를 사용 중이면 `NEXT_DIST_DIR=.next-admin npm run build`로 독립 검증 후 `NEXT_DIST_DIR=.next-admin npm run start -- --port 3101`

브라우저 검증: 6개 메뉴의 Empty State, Mock 계정 발급, 공지 생성·삭제, Discord 전송 상태, 출결 소명 409 무효화, 챕터 수정, 채점 및 제출 잠금, 문항 편집·복습 매핑, 평가 게시. 검증용 데이터는 초기화했습니다.
